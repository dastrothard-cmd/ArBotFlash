# Licensing and attribution policy

## Finished Tree ID Trainer source

The uploaded Tree ID Trainer source and theme artwork are treated as user-supplied project materials. They are preserved inside ArbotFlash only as a read-only migration and behavioural reference.

Before theme artwork or another non-code asset is published in ArbotFlash, its ownership or reusable licence must be confirmed. Factual names are not treated the same as copied creative text, artwork, photographs or audio.

## Taxonomy and biodiversity records

Every external import must retain:

- Dataset name and publisher
- Source record ID
- Release or retrieval date
- Licence
- Original URL where available
- Transformations performed by ArbotFlash
- Verification and review status

A combined species page may contain records from several sources. They remain separately attributable rather than being blended into one anonymous profile.

## Species images

Every image record must include, where applicable:

- Creator or photographer
- Original source page
- File or record identifier
- Licence code and licence URL
- Required attribution text
- Modifications
- Retrieval date
- Taxon and diagnostic category
- Location and date
- Verification status

An image without sufficient licence information is not publishable, even when it is easy to download.

## Wikipedia, Wikidata and Wikimedia Commons

- Wikidata structured data is supplemental linked data and must follow its applicable terms.
- Wikipedia prose requires page/revision attribution and compatible share-alike handling when reused or adapted.
- Wikimedia Commons licences apply per file. Commons does not provide one blanket image licence.

ArbotFlash should prefer short attributed summaries and links rather than copying whole articles.

## Community and Indigenous knowledge

Community submissions require contributor terms and a clear licence. Indigenous ecological or cultural knowledge requires appropriate attribution, permission, sensitivity controls and the ability to restrict information that should not be made public.

## AI-generated content

AI-assisted text is marked as draft and has no automatic authority. AI cannot remove source obligations, invent a licence, fabricate a citation or promote its own draft to verified status.

## v0.4 Wikimedia Commons slice

The first ten media records are not copied from a generic image search result. Each one records an individual Commons file page, creator and licence.

Licences represented in the initial slice include:

- CC BY 2.5 AU
- CC BY-SA 3.0
- CC BY-SA 4.0
- Public domain

ArbotFlash links both the source file page and licence page from the profile. A future offline regional pack must either cache a licence-compatible transformed copy with its attribution metadata or leave the image online-only. It must not separate an offline image from its creator and licence record.
