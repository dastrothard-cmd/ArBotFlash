# ArbotFlash filter catalogue

ArbotFlash v0.3 contains **154 filter definitions**. They use one universal filter engine with organism-specific groups.

The 80-tree seed currently populates only values known from the completed trainer or safely established by the seed collection itself. Empty biological traits are not invented merely to make more controls appear.

## How stacking works

- Multiple values in one filter use **OR**.
- Different filters use **AND**.
- Every selected value appears as a removable chip.
- Facets remain visible so another value can be added after one is selected.

Example:

```text
Family: Myrtaceae OR Fabaceae
AND Plant form: Tree
AND Taxonomy reconciliation: Pending authoritative match
```
